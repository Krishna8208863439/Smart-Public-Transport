**SmartTransit AI** is a production-ready, enterprise-grade AI-powered Smart City Mobility & Civic Infrastructure Operating System. It unifies real-time transit tracking, AI traffic signal queue optimization, computer vision violation detection, IoT infrastructure predictive maintenance, digital QR/NFC ticketing, citizen civic complaint reporting, emergency SOS routing, and environmental sustainability analytics.

---

## ✨ Features

- **🏙️ Executive Smart City Mobility Dashboard**: Real-time KPI cards for active fleet, AI traffic congestion index, IoT asset health scores, and carbon offset tracking.
- **🗺️ Interactive City GIS Telemetry Map**: Custom CartoDB dark cyber Leaflet map rendering live moving buses, metro lines, smart signals, and emergency green corridors.
- **🧭 AI Intermodal Journey Planner**: Route optimization comparing *Fastest*, *Eco-Friendly*, *Least Congested*, and *Lowest Cost* itineraries with 1-click QR ticketing.
- **🚦 AI Traffic Management & Computer Vision Simulator**: Adaptive signal timing control, manual junction overrides, and YOLOv11 CCTV ANPR (Automatic Number Plate Recognition) violation logs.
- **🏗️ IoT Infrastructure & Predictive Maintenance**: Real-time sensor telemetry (vibration, strain, moisture, power load) with ML failure risk scoring and automated work order dispatch.
- **🎫 Digital Wallet & NFC Card Simulator**: QR code transit pass generator, tap-to-pay turnstile gate simulator, and monthly subscription passes.
- **📢 Smart Civic Complaint Portal**: Citizen issue reporting with instant AI photo verification, severity rating, and department routing.
- **🌿 Environmental Monitoring & Carbon Credit Ledger**: Air quality index (AQI) tracking, noise pollution meters, and EV fleet carbon offset metrics.
- **🚨 Emergency SOS Dispatch Center**: Priority green corridor wave activation for ambulances & fire response.
- **🤖 Smart City AI Copilot**: Natural language assistant for instant city data summaries and transit advice.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Data Visualization**: Recharts, Leaflet.js
- **State & Telemetry Engine**: React Context + Real-Time Telemetry Simulation Engine

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Krishna8208863439/Smart-Public-Transport.git
   cd Smart-Public-Transport
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
